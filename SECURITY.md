# Security Policy

## Supported releases

Security fixes are provided for the latest published release of Homebridge Magic Home Pro. Users should update to the newest available version before reporting an issue that may already have been corrected.

## Reporting a vulnerability

Please do not disclose a suspected vulnerability in a public issue, discussion, pull request, or social-media post before it has been investigated and a fix is available.

Use GitHub [Private Vulnerability Reporting](https://github.com/Ai-Lampy/homebridge-magic-home-pro/security/advisories/new) to submit the report privately. An acknowledgement should be provided within seven days. Investigation and remediation time will depend on the severity and complexity of the issue.

Include:

- the affected plugin, Homebridge, and Node.js versions;
- the controller model or protocol family, if relevant;
- a clear description of the impact and reproduction steps;
- logs or proof-of-concept material needed to reproduce the issue; and
- any suggested mitigation or fix.

Remove credentials, public IP addresses, private network details, and unrelated personal information from supporting material.
